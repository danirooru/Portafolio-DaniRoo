# Portafolio de Daniela Róo Rubí

Portafolio personal de **Daniela Róo Rubí**, diseñadora gráfica digital. Reúne mi presentación, formación, experiencia, habilidades y doce proyectos de identidad de marca, empaque, ilustración, campañas, modelado 3D y UX/UI.

El proyecto incluye una landing responsiva de una sola página, desarrollada con HTML, CSS y JavaScript, y una página que presenta su sistema de diseño. La landing permite filtrar proyectos por categoría y abrir sus galerías de imágenes.
